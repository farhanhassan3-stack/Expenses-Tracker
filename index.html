Pelaksanaan Pada Telefon Android Sebenar

Web browser demi keselamatan sistem operasi tidak boleh membaca notifikasi peranti secara automatik tanpa kebenaran sistem native. Untuk menjadikan aplikasi ini berfungsi **100% automatik di latar belakang** pada telefon Android anda, pilih salah satu kaedah berikut:

Mekanisme Auto-Buka Skrin Android (Intent & Deep Link)

Pada peranti Android fizikal, perkhidmatan NotificationListenerService mengecam SMS/Notifikasi bank, memasukkan data ke pangkalan data tempatan, dan mencetuskan Android Intent / Deep Link (cth: expensetracker://confirm-category?amount=45.00) untuk membuka aplikasi secara terus ke skrin penentuan kategori.

Kaedah 1: Guna Tasker / MacroDroid (Paling Mudah)

  1. Muat turun MacroDroid atau Tasker dari Play Store.
  2. Buat Trigger: Notifikasi Diterima daripada aplikasi Maybank / CIMB / TNG.
  3. Buat Action: Ekstrak teks notifikasi & hantar via HTTP POST / Webhook ke aplikasi anda.

Kaedah 2: Flutter / React Native App

Bungkus aplikasi ini menggunakan React Native / Flutter dengan plugin android-notification-listener untuk membaca SMS & Push Notifications secara latar belakang (Background Service).
